## Decision implemented

GitHub Actions cron is no longer the intended production scheduler for either
Korean RSS collection or the two daily reports. Stored run records showed that
missed GitHub cron invocations can permanently lose RSS items once a publisher's
rolling buffer advances. The repository now contains a Cloudflare Workers Free
dispatcher, `infra/cloudflare-scheduler/`, which invokes GitHub Actions through
`workflow_dispatch` and checks for stale or failed runs.

This is code-ready, not deployed. Until Ricky creates the Worker and its secret,
the current deployed GitHub schedules remain the live scheduler.

## Cost and safety boundaries

- The Worker stores only a fine-grained GitHub PAT restricted to `Actions: write`
  for this repository. Rotate it every 90 days.
- The Worker dispatches workflows only; it has no contents permission and no
  market-data or LLM credential.
- `synthesis.enabled: false` fails closed before red-team or commentary can call
  a vendor. Anthropic is therefore unnecessary for normal production runs.
- Scoring remains subject to the existing 180-pair run cap and $5 account limit.
  No historical scoring backfill is authorized.
- `news_polarity` remains a deferred component diagnostic and does not enter the
  frozen composite rating before the 2026-11-13 gate.
